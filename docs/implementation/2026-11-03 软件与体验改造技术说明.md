# 2026-11-03 软件与体验改造技术说明

> 范围：`software/app/`（网页 + Android 壳共用 UI）、`software/app-android/`、`software/backend/`。
> 不改：`protocol/contract.yaml`、固件 `hardware/toy-sidecar/`、`governor.js` 的规则、`resume` 路径。
> 产品口径见 [`product-decisions-2026-11.md`](../product-decisions-2026-11.md)（在 PR #2）与 [`产品架构.md`](../architecture/产品架构.md)。

## 1. 前提

| 项 | 现状 |
| --- | --- |
| 硬件 | 萨福原厂板。没有我们的 ESP32，没有温度、压力、六轴传感器 |
| 配套 App | 轻喃（qingnan）。源码、安装包、蓝牙协议都还没拿到 |
| 本次方向 | 只做软件与体验，不碰硬件 |
| 设备接口 | 指令仍走仓库里 Nascent 自己的 `Nascent-Toy` GATT。接萨福板要等协议，届时只换传输层 |

**安全不变量照旧**：停止永远可发；没有远程 `resume`；LLM 不直接出电机指令；音频不上云；安全功能不收费。

**新增风险**：本地急停、PWM 上限、断连归零原本由我们的固件保证。换成萨福板后，这些取决于萨福固件，App 只能尽力兜底。拿到协议后第一件事是实测萨福板的停止和断连行为。

## 3. 后端：模型 JSON 修补（#3）

**问题**：模型输出常带 Markdown 代码块、首尾说明、尾随逗号，或被 `max_tokens` 截断。原来一律解析失败，退回桩台词。

**实现**：`app/services/json_repair.py` 的 `parse_model_json(text, allow_truncated=False) -> (dict, truncated)`。

1. 剥掉代码块，尝试直接 `json.loads`。
2. 取第一个 `{` 到最后一个 `}`，去尾随逗号再试。
3. 仅当 `allow_truncated=True` 时，用括号栈补齐未闭合的字符串和括号。

| 调用处 | 允许补截断 | 补截断后的处理 |
| --- | --- | --- |
| Chat `generate_turn` | 是 | 丢弃 `memory_proposals`、`skill_proposals` |
| 身体笔记 `generate_body_insight` | 是 | 丢弃 `insight_candidate` |
| Control `generate_control` | 否 | 截断仍退回 `hold` |
| 模板 `generate_template` | 否 | 截断仍返回 `None` |

修补后照样过 Pydantic（`extra="forbid"`）和原有策略，Chat 的 `action` 仍强制为空。

## 4. 自我控制体验（#4）

### 4.1 盲操滑动面板

- 模块：`js/control-gesture.js`。`levelFromDrag(start, dy, max)`：每 42px 一档，夹在 1 到 levelMax。
- 用 Pointer Events。滑动中只更新数字和触感，**松手才提交一次** `set_level`（与滑杆一致）。
- 静止按住 800ms 等于按停止，走同一个 `stop`。没有用 `set_level(0)`，因为按《硬件实机已验证 API 基准》，它不能当安全停机。
- 偏好 `prefs.controlGesture`，默认开启，可切回滑杆。

### 4.2 停止后安抚页

- 只有在自我控制页里停止**成功**后才显示。文案「已经停下了」，可选本地 Web Audio 合成的低通雨声，并给出「安全与卫生指南」入口。
- 离开控制页自动关掉，雨声也随之停止。

### 4.3 屏幕常亮

- 条件：`shouldKeepScreenOn({tab, page, connected})`，即连着设备，或停留在亲密时刻的二级页面，并且页面可见。
- 网页用 Screen Wake Lock API。Android WebView 不支持这个 API，所以新增 `NascentShell.setKeepScreenOn(boolean)`，用 `FLAG_KEEP_SCREEN_ON` 开关。
- Android 增加 `VIBRATE` 权限，`navigator.vibrate` 才会生效。

## 5. 信息架构与频率广场（#5）

### 5.1 三栏

- `routes.js`：`NAV_TABS = ["intimacy","records","settings"]`，默认 `#/intimacy`。`legacyHeartTarget()` 把旧的 `#/heart` 跳到 `#/intimacy`。
- 删除心绪页的渲染和交互（打卡、知识卡、收藏、分享）。`heart.js` 的数据模块保留，供导出和清除使用。
- 亲密首页改为三张横排等高卡片，底部为导航栏留出固定空间。

### 5.2 频率广场

**数据模型**（`js/frequency.js`）：

```text
Frequency { id, name(≤16), tags(≤3, 每个≤6字), stepMs(500–3000), steps: int[4–32] ∈ 1..9 }
```

- 精选：6 段官方频率，最高 6 档。
- 我的：保存在 `localStorage`（`nascent.frequency.mine`），收藏存在 `nascent.frequency.favorites`。
- 编辑器：12 拍竖向滑杆，节拍有快 / 中 / 慢三档（500 / 1000 / 2000ms）。

**分享码**：

```text
NLF1:<base64url(JSON{ n: 名字, t: 标签[], s: 步长ms, l: "档位数字串" })>
```

- 只包含名字、标签、步长和档位，不含设备或用户信息。
- 解码时会从一整段文字里找出分享码；档位不在 1–9、步长越界、长度不对、base64 坏掉，一律拒绝。

**播放器** `FrequencyPlayer`：

- 循环下发 `set_level`，每一步都走 `sendCommand()` → Governor，按**手动**指令发送。理由：播放是用户主动点的，相当于原机内置的模式。没有传感器时，`automatic` 指令永远会被「使用状态 unknown」挡住。
- 任何一次下发被拒（已停止、断连等）立即停下，不重试。
- 会停止播放并发送 `stop` 的情况：按停止或「停下」、离开频率广场、页面切到后台、设备断连。
- 进入频率广场时，和自我控制一样先切到 `free` 模式。

**社区**：目前只做了分享码这条点对点闭环。公开投稿需要后端存储、内容审核和年龄门禁，另案处理。

### 5.3 去掉温度、压力显示

- 情景聊天的温感/压力/心率标签、记录页和单次详情的温压文案、图表上的压力柱，都去掉了。图表只剩档位。
- 「这次数据会去哪里」改为「本机只记录档位和时长」。
- 发给 AI 的 `sensor_context` 字段**没动**：后端 Control 的 `_control_must_hold` 要求温度/压力质量不能是 unknown，所以没有传感器时「设备自动调节」实际永远是 hold。按产品要求入口保留，等阅读模式的预置曲线再改。

### 5.4 情景聊天

- 顶栏只保留名字和头像。「语音通话」「忘掉他记得的事」移到点击头像弹出的底部菜单。
- 回车发送：`isSendEnter(e)` 要求 `key==="Enter"`、没按 Shift、`!isComposing`、`keyCode!==229`（输入法选字时的回车不算），textarea 设了 `enterkeyhint="send"`。
- 修复：AI 回复中再次提交，原来会清空输入框但消息没发出去；现在发送中直接忽略提交，保留输入内容。

## 6. 内置人设：疏衡、淮汐、柚汀（本 PR）

**来源**：`docs/architecture/personas/` 下的加深人设文档（在 #1）。

**后端** `app/services/personas/builtin_deepened.py`：

- `DeepenedPersona(persona_id, char_name, body)`。`body` 写这个人自己的内容：身份、生活锚点、会犯的错与摩擦、日常/亲密语气、称呼三档、档位与心率怎么接话。
- `SHARED_RULES`：三人共用的情绪判断、反爹味、软检查与硬停止、内容边界、记忆、反模板、优先级。安全规则只有这一份，单个人设里不另写。

- `prompt_builder.build_messages`：命中加深人设时用 `fill_deepened_prompt`；`gentle` 仍走固有人设 001；其他走自定义角色卡。
